### Issues encountered + resolved
1. **WP `redirect_canonical` hijacking taxonomy archive URLs** — when a term and a CPT post share a slug ("brockenhurst" exists as both area_taxonomy term AND area CPT post), WP canonical redirect routes the term URL to the post URL, bypassing my `template_redirect` 301 to the pretty URL. Fix: added `redirect_canonical` filter that returns `false` for any URL path matching the taxonomy archive patterns + bumped my `template_redirect` priority to 5 (runs before WP's default 10).
2. **Salt Cottage (137) + the-shepherd (164) had no `tier` meta** — Phase 5 seeder bailed before setting it on Salt; my PHP property creator skipped the-shepherd because its sideload failed. Filter query uses `meta_key=tier` for editor sort, which excludes posts missing that meta. Fix: `wp eval` set tier=2 on both. /cottages/ now shows 12/12 cards.
3. **Cloudways Varnish + LiteSpeed cached old 404 responses** for the redirect-test URLs. Real fix worked, but verification showed false 404s. Cache-bust query string (`?bust=$(date +%s)`) confirmed correct 301 behaviour.
4. **Phase 2 page-hero.php** only accepted `heading` + `image`; Phase 6 templates pass `title` + `image_url`. Extended page-hero.php to accept both arg pairs (PHP 7.4 compatible — title takes precedence over heading; image_url takes precedence over image).
5. **Phase 6 prompt's verification** referenced `/area-taxonomy/{slug}/` as the "native URL" but Phase 3 already remapped area_taxonomy to `cottages/area/{slug}/`. Both URL forms now have explicit redirect handling.

### Critical lesson — ACF Options field-name collision

The Phase 3 schema registers field-groups for About/How-We-Choose/Contact/Oracle/Newsletter Options sub-pages with **field NAMES that collide** (`hero_h1`, `hero_dek`, `hero_image` reused across pages — only the field KEYS differ). The result: About's hero_h1 returned Oracle's "Ask the Oracle." after the seeder finished.

**Fix** (applied immediately): re-seed using **menu_slug as post_id**:
```php
update_field('hero_h1', "We're Jamie and Lauren.", 'site-settings-about');
get_field('hero_h1', 'site-settings-about');  // returns "We're Jamie and Lauren."
```
ACF stores scoped writes as wp_options row `{slug}_{field_name}` — no collision.

**All Phase 10A templates read with scoped post_ids**:
- About: `get_field(X, 'site-settings-about')`
- HWC:   `get_field(X, 'site-settings-how-we-choose')`
- Contact: `get_field(X, 'site-settings-contact')`
- Oracle: `get_field(X, 'site-settings-oracle')`
- Brand: `get_field(X, 'site-settings-brand')`
- Header/Footer: `get_field(X, 'site-settings-header-footer')`

Phase 5 homepage Options work fine with `'option'` because their field names (`hero_eyebrow`, `editor_picks`, etc) are unique across all groups. The collision only affects Phase 10A's About/HWC/Contact/Oracle/Newsletter heroes.

### Phase 10B lessons
- **Auto-TOC from wysiwyg via DOMDocument**: server-side parse, inject `id` on every h2, return modified HTML + TOC items array. `wp_kses_allowed_html('post')` doesn't allow `id` on h2 by default — must explicitly enable. Wrap input as `<?xml encoding="UTF-8"><div>...</div>` for proper UTF-8 + isolation, then iterate `documentElement->childNodes` to serialize back without the wrapper. libxml errors suppressed with `libxml_use_internal_errors(true)` because wysiwyg HTML is often imperfect.
- **Single template, multiple posts via slug match**: page-legal.php is one file, assigned to 4 page posts; each instance reads its own slug via `get_post_field('post_name')` and finds the matching repeater row. Avoids 4 near-identical templates. Pattern reusable wherever you have a "kind of pages" sharing structure but differing only in content.
- **`http_response_code(404)` in 404.php is critical for SEO** — without it WP serves 200 and search engines index the not-found page. Set BEFORE `get_header()`.
- **`template_redirect` priority < 10** to fire before `redirect_canonical`. Phase 10B newsletter redirect uses priority 4 (lower than Phase 6's priority 5 taxonomy redirects). Order between sub-10 priorities doesn't matter as long as none collide on the same URL.

### Phase 12c lessons
- **Scraper IS an importer**: extending NFEdit_Feed_Adapter_Base means scraped properties land in same `property` post type, write same canonical fields, log to same wp_nfedit_feed_log table, appear in same admin UI as Awin-feed properties. Future no-feed partners (Cool Stays direct, Rural Retreats, Luxury Cottages) plug in by writing one new ~150-line scraper class.
- **Park assignment via link-counting** is more robust than text-search when every page footer mentions all parks. Counter pattern: count `href="/holidays/locations/{slug}"` occurrences, take the max. Falls naturally because main content adds 2-4 extra mentions for the home park.
- **Image dedup by canonical filename** (not URL): Glide CDN serves N size-variants per image, all with different hash paths. Walk URL backward, find first segment ending in image extension — that's the canonical name. Coppertree had 76 raw matches → 19 unique. Without dedup, importer would sideload 4x the necessary images.
- **`_nfedit_scrape_review_required` post meta** is the curation gate. Templates can render "DRAFT — needs editorial review" notice only on backend; scraped properties stay `draft` status until Lauren manually reviews + publishes. Field-mapper sets this only when `_scraped=true` is on canonical (set by admin-post handler before mapper.apply()).
- **Per-host robots.txt cache** at 24h TTL, conservative defaults (no robots.txt = allow_all, malformed = treat as no rules). Empty `Disallow:` under `User-agent: *` = explicit allow_all flag.
- **Glide image URL format**: `https://fls-{uuid}.laravel.cloud/glide/containers/images/{path}/{filename}/{cache-hash}/{filename}`. Path-segment match is the only reliable filter for "is this image for property X?"
- **`set_time_limit(0)` in admin-post handler**: scraper run takes 1-3 minutes (5-15 detail pages × 2-4s delay + parse + image sideloads). Disable PHP execution timeout for the duration.
- **PHP 7.4 typed-property gotcha**: when extending an abstract class with typed properties, the subclass must match exactly. Adapter base uses `protected $api_key;` (untyped) for compat with PHP 7.4 minimum; the prompt's `private string $api_key;` was PHP 7.4+ but I kept the looser version to avoid future PHP-version friction.
